# 00. 概要と方針

## 1. 製品

**Ohyna**（Open Hybrid Note App／おひな、版 1.0.0）は、日本語文書を主対象に、Markdown から A4 の印刷向け PDF を作成するサービスです。ブラウザ上で文書を編集・確認し、PDF を保存します。

扱う単位は **単一文書**です。1 つの Markdown を編集し、1 つの PDF を出力します（GUI、HTTP `POST /preview`・`/pdf`・`/analyze`、CLI `pdf` / `serve`）。

| 用途 | 内容 |
|------|------|
| 編集 | Markdown 本文とドキュメント設定（表紙・色・フォントなど） |
| 検査 | 問題があるあいだはプレビュー更新と PDF 作成を止める |
| プレビュー | 用紙イメージで体裁・図・数式を確認する |
| PDF | 検査通過後に生成し、確認のうえ保存する |

---

## 2. 方針

1. **文書形式は Ohyna Markdown**（Markdown を基礎とした製品プロファイル。使える記法は本ヘルプのマニュアルと仕様書に従う）
2. **図は Mermaid**（`mermaid code` はコード表示）
3. **数式は KaTeX**（`$...$` / `$$...$$` など、および math 系フェンス）
4. **体裁は文書先頭の設定**（`ohyna:`）で定義する
5. **検査で error があるあいだは、プレビュー更新と PDF 作成を進めない**
6. **プレビューは編集確認用、配布・印刷の基準は PDF**

---

## 3. 想定用途

- 手順書、仕様書、報告書を Markdown で作成し、PDF で配布する
- 画面で体裁を確認しながら 1 文書を仕上げる

サーバの構築や公開設定の変更、他利用者への共有方法は、サービス提供者の運用に従います。

---

## 4. 利用上の前提

| 項目 | 内容 |
|------|------|
| 提供形態 | 組織等が用意したサーバ上のサービスとして、ブラウザから利用する |
| 必須のドキュメント設定 | タイトル、色テーマ、本文フォント（またはカスタム）、言語 |
| 最終確認 | 画面プレビューではなく **PDF 作成後の確認** |
| データの扱い | 編集・プレビュー・PDF 生成のため、入力は接続先サービスへ送信される。秘密情報の入力は避ける |
| 不具合・問い合わせ | サービス提供者の窓口へ |

---

| 層 | 内容 |

| PDF | ブラウザ印刷エンジン相当 |
