# 03. 文書設定リファレンス

体裁は Markdown 先頭の YAML front matter（`ohyna:`）で定義します。

構文は YAML、キーの意味は本製品契約です。準拠の切り分けは [10-準拠仕様マップ.md](./10-準拠仕様マップ.md) §6 を参照してください。

---

## 1. Front matter

### 1.1 形式

文書の先頭（任意の HTML コメントの直後）に次の形で書きます。

```yaml
---
ohyna:
  title: 文書タイトル
  style: blue
  font: noto
  lang: ja
  cover: true
  subtitle: 副題
  label: DOC
  meta:
    - 発行元
    - 2026-07
---

# 本文見出し
```

規則:

| 規則 | 内容 |
|------|------|
| 名前空間 | 設定は **`ohyna:` 配下のみ** |
| キー名 | **camelCase のみ**（`font_size` などの snake_case はエラー） |
| 受理キー | `ohyna:` 配下の公式キーのみ（本書の表） |
| BOM | 先頭の UTF-8 BOM は無視 |
| コメント | front matter 直前の `<!-- ... -->` は除去してから解釈 |

`ohyna` 以外のルートキーがあっても保持されます（GUI の「適用」でも `ohyna` 以外は消しません）。

### 1.2 キー一覧

| キー | 型 | 必須 | 未指定時の扱い | 意味 |
|------|-----|------|----------------|------|
| `title` | string | **必須**（解析・GUI） | 空は未設定。表示時は本文先頭 `#` をフォールバックしうる | 表紙タイトル・HTML `<title>` |
| `style` | string | **必須**（解析・GUI） | 解決処理では `"blue"` | 色テーマ名 |
| `font` | string | **必須**（`fontFamily` があれば代替可） | 解決処理では `"noto"` | 本文フォントプリセット |
| `lang` | string | **必須**（解析・GUI） | 解決処理では `"ja"` | HTML の `lang` 属性へ載せる任意文字列（**BCP 47 を推奨**。IANA 完全検証はしない）。フォントや組版エンジンは切り替えない |
| `cover` | bool | 任意 | 概ね表紙あり | 表紙の有無 |
| `subtitle` | string | 任意 | `""` | 表紙サブタイトル |
| `label` | string | 任意 | `""` | 表紙パートラベル |
| `meta` | string[] または改行区切り string | 任意 | `[]` | 表紙フッタ行 |
| `rounded` | bool | 任意 | `true` | 角丸。`false` なら `radius` は `none` 相当 |
| `radius` | `none` / `sm` / `md` / `lg` | 任意 | `md` | 角丸サイズ |
| `fontFamily` | string | 任意 | なし | カスタム CSS `font-family`（プリセットを上書き） |
| `fontMono` | string | 任意 | Cascadia / Consolas 系 | コード用フォント |
| `fontSize` | CSS 長さ | 任意 | `10.5pt` | 本文サイズ（`pt`/`px`/`em`/`rem`/`%`） |
| `lineHeight` | 数値文字列 | 任意 | `1.7` | 行間 |
| `coverPattern` | 表紙キー | 任意 | `noise` | 表紙背景パターン |
| `coverGradient` | bool | 任意 | `true` | 設定として保持。印刷 CSS の見た目には使わない（表紙は画像選択が本体） |
| `headingBand` | bool | 任意 | `true` | h2 の帯背景 |
| `tableHeaderFill` | bool | 任意 | `true` | 表ヘッダの濃色塗り |
| `letterSpacing` | CSS | 任意 | `0` | 字間 |
| `author` / `version` / `date` | string | 任意 | `""` | 文書メタ。`meta` が空なら表紙フッタへ自動流し込み |
| `pageSize` | `a4`/`a5`/`b5`/`letter` | 任意 | `a4` | 用紙サイズ |
| `pageOrientation` | `portrait`/`landscape` | 任意 | `portrait` | 向き |
| `marginPreset` | `narrow`/`normal`/`wide`/`custom` | 任意 | `normal` | 余白プリセット |
| `marginTop` 等 | number（mm） | 任意 | プリセット値 | `custom` 時の上下左右 |
| `pageHeader` / `pageFooter` | 定型キー | 任意 | `none` | 本文ページのヘッダ／フッタ（表紙 `meta` とは別） |
| `pageHeaderText` / `pageFooterText` | string | 任意 | `""` | 定型が `custom` のとき |
| `toc` | bool | 任意 | `false` | 自動目次（`[TOC]` 挿入） |
| `tocDepth` | `2`/`3` | 任意 | `3` | 目次の見出し深さ |
| `codeLineNumbers` | bool | 任意 | `false` | コード行番号 |
| `codeWrap` | bool | 任意 | `false` | コード折り返し |
| `codeFontSize` | CSS 長さ | 任意 | （本文連動） | コード専用サイズ |
| `linkUnderline` | bool | 任意 | `false` | リンク下線 |
| `linkThemeColor` | bool | 任意 | `true` | リンク色をテーマに合わせる |
| `watermark` | `none`/`draft`/`confidential`/`custom` | 任意 | `none` | 透かし |
| `watermarkText` | string | 任意 | `""` | `custom` 時の文言 |
| `design` | object | 任意 | — | 上記レイアウト系をネストして書ける。フラットキーとマージ（ネスト側が優先） |

**必須の判定箇所**

- 画面の静的解析、およびプレビュー／PDF のゲート（必須キーが欠けると進めません）

### 1.3 色テーマ（`style`）

製品が用意するテーマ名（画面のドキュメント設定で選べます）:

`blue`, `sky`, `indigo`, `celadon`, `forest`, `yellow`, `default`, `gold`, `orange`, `sakura`, `red`, `wine`, `purple`, `brown`, `neutral`, `dark`

図（Mermaid）の色と、印刷 CSS のアクセント色の両方に使います。

### 1.4 フォント

構成:

| 対象 | キー | 内容 |
|------|------|------|
| 本文 | `font` | プリセット（下表）。和文／欧文の優先ファミリーが異なる |
| 本文上書き | `fontFamily` | 任意の CSS `font-family` スタック（指定時は `font` より優先） |
| コード | `fontMono` | コード用スタック。空なら Cascadia Mono → Consolas → Courier New |
| サイズ／行間 | `fontSize` / `lineHeight` | 本文の基本サイズと行間 |

#### 本文プリセット（`font`）

| キー | 和文（優先） | 欧文（優先） |
|------|--------------|--------------|
| `noto` | Noto Sans JP | Segoe UI |
| `gothic` | 游ゴシック / ヒラギノ角ゴ / Noto Sans JP | Segoe UI |
| `mincho` | Noto Serif JP / 游明朝 / ヒラギノ明朝 | （和文スタックに追随） |
| `sans` | Noto Sans JP（フォールバック） | Segoe UI / system-ui |
| `serif` | Noto Serif JP（フォールバック） | Georgia / Times New Roman |
| `inter` | Noto Sans JP | Inter |
| `mono` | （欧文等幅を共用） | IBM Plex Mono |

#### コードフォント（`fontMono`）

GUI では次のプリセットから選び、YAML には CSS スタックを書き込みます（既定プリセット選択時はキー省略＝空）。

| GUI | 書き込まれるスタック（要約） |
|-----|------------------------------|
| Cascadia / Consolas（既定） | 空（実行時 Cascadia → Consolas → Courier New） |
| IBM Plex Mono | `"IBM Plex Mono", …` |
| Consolas | `Consolas, "Courier New", monospace` |
| カスタム | 利用者が入力した CSS |

Google Fonts から読み込むファミリーはプリセットごとに決まります。`fontFamily` に Noto が無い場合は日本語安全のため Noto Sans JP を追加することがあります。

### 1.7 設定値の優先順位（共通）

同名の設定が複数あるときの解決規則（画面利用では主に 2〜3）:

1. **提供者が別経路で明示した非空の上書き**（ある場合）  
2. **front matter**（`ohyna:`）  
3. **テーマ／製品既定値**（例: `cover` の既定 true）

| 入力の形 | 解釈 |
|----------|------|
| キーなし／`null`／省略 | **未指定（UNSET）** → 下位へフォールバック |
| 空文字列 `""` | **未指定と同じ**（明示クリアではない） |
| 非空の値 | **VALUE** → 採用 |

将来「明示的に空にする」が必要になった場合は別表現を導入する。現状の空文字はフォールバックする。
