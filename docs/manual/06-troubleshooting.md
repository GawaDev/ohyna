# 困ったとき

よくある状態と対処です。解決しない場合は [GitHub Issues](https://github.com/GawaDev/ohyna/issues) へ。

---

## 1. プレビューが更新されない／「未更新」のまま

| 確認すること | 対処 |
|--------------|------|
| 「問題」にエラーが出ていないか | メッセージに従って本文またはドキュメント設定を直す。問題を直すと更新できます |
| ドキュメント設定の必須項目（タイトル・色テーマ・フォント・言語） | 「問題」または「出力」の内容に従い、「ドキュメント設定」で直して「適用」する |
| 「確認中」の表示が続いていないか | しばらく待つ。終わらない場合は本文を少し編集して再検査を促す |

---

## 2. PDFを作成できない／ボタンが押せない

| 確認すること | 対処 |
|--------------|------|
| 検査の問題 | 「問題」の内容を直す。問題を直すと PDFを作成できます |
| ドキュメント設定の必須欠落 | 「出力」を確認し、「ドキュメント設定」を開いて適用する |
| 生成中の表示 | 完了まで待つ。失敗時は赤い通知の内容を確認する |

---

## 3. 保存できない・開いたファイルと別の場所にしか書けない

| 状況 | 対処 |
|------|------|
| 「保存」なのに毎回場所を聞かれる | 「名前を付けて保存…」で場所を指定する。ブラウザが直接上書きに対応していないか、権限が無い場合があります |
| 開くときに何も起きない | ダイアログでキャンセルしていないか確認する |
| 起動しても前回のファイルが開かない | ヘッダの「前回のファイルを開く」を押してアクセスを許可する。拒否・削除・移動のときは空のドキュメントになる。起動直後だけではブラウザが権限ダイアログを出せない |
| 未保存の警告が出る | 内容を残すなら先に「保存」する。破棄してよいときだけ続行する |

---

## 4. 図（Mermaid）が赤い枠になる

- 図として描くときはフェンスの言語名を `mermaid` にする。ソースをコードとして載せるときは `mermaid code` または `text` を使う。  
- 図のソースに構文誤りが無いか、プレビュー内のメッセージを読む。  
- 検査で問題が出ている場合は、「問題」のメッセージを先に直す。  

---

## 5. 数式がエラーになる

- `$` / `$$` の対応が取れているか確認する。  
- コードブロック内の `$` は通常の文字として扱われる。数式は本文側に書く。  
- KaTeX が解釈できる書き方になっているか見直す。  

---

## 6. 表紙や色が期待と違う

| 現象 | 確認 |
|------|------|
| 表紙が無い | 「表紙を付ける」がオンか、「適用」したか |
| 色が変わらない | 「色・言語」の色テーマを変え、「適用」したか。色は表紙以外（見出し帯・表・図）にも効きます |
| 表紙の柄 | 「表紙デザイン」と色テーマの組み合わせを確認し、「適用」する |

---

## 7. 折りたたみの表示

プレビューと PDF では折りたたみを常に展開して表示します。

---

## 8. 画像が出ない

画像は `https:` / `http:` / `data:` の URL で指定します。パスや URL を空にせず書いてください。

---

## 9. それでも解決しないとき

次を控えてから連絡すると早く伝わります。

- 画面上部中央の通知メッセージの全文  
- 「問題」に出ているメッセージ  
- 再現手順（開いた操作、ドキュメント設定の有無、問題の記法）  

| 窓口 | 用途 |
|------|------|
| [GitHub Issues](https://github.com/GawaDev/ohyna/issues) | 製品の不具合・要望 |
| [セキュリティ報告](https://github.com/GawaDev/ohyna/security/advisories/new) | 脆弱性 |
| サービス提供者 | サーバ運用・アカウント・組織ポリシーなど環境固有の問い合わせ |

ソースとライセンスの一覧は [プロジェクトについて](./07-about.md) にあります。
