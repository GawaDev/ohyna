# ドキュメント設定

ドキュメントの表紙・色・フォントなどは「ドキュメント設定」画面で編集します。適用すると、ドキュメント先頭の設定ブロック（YAML の `ohyna:`）に書き戻されます。ディスクへの保存はファイルメニューの「保存」で行います。

---

## 1. 画面のタブ構成

| タブ | ここで決めること |
|------|------------------|
| 色・言語 | 色テーマ、言語コード |
| 表紙 | 表紙の有無と背景、タイトルなどの文言、著者・版・日付、プレビュー |
| フォント・体裁 | 本文／コードフォント、用途プリセット、文字サイズ・行間・字間、角丸・リンク |
| 用紙・余白 | 用紙サイズ・向き、余白（狭め／標準／広め／カスタム mm） |
| ページ・コード | 本文ヘッダ／フッタ、目次、コードブロック、透かし |

色テーマは表紙専用ではありません。見出しの帯、表のヘッダ、図（Mermaid）のアクセント色など、ドキュメント全体に効きます。

---

## 2. 必須項目

次の 4 つは必須です。未設定のあいだはプレビュー更新と PDF 生成ができません。

| 項目 | 設定キー | 説明 |
|------|----------|------|
| タイトル | `title` | 表紙中央の主見出し。HTML のページタイトルにも使います |
| 色テーマ | `style` | ドキュメント全体の色（後述の一覧から選択） |
| フォント | `font`（またはカスタムの `fontFamily`） | 本文のフォントプリセット |
| 言語 | `lang` | ドキュメントの言語（例: `ja`）。フォントは別タブで指定します |

---

## 3. 色・言語タブ

### 3.1 色テーマ（`style`）

次のいずれかを選びます。表紙の背景色、見出し帯、表ヘッダ、Mermaid ダイアグラムの色に使われます。

| 値 | 表示名 |
|----|--------|
| `blue` | 縹（はなだ／青） |
| `sky` | 空色（そらいろ／水色） |
| `indigo` | 藍（あい／紺） |
| `celadon` | 青磁（せいじ／青緑） |
| `forest` | 常磐（ときわ／緑） |
| `yellow` | 山吹（やまぶき／黄） |
| `default` | 琥珀（こはく／黄茶） |
| `gold` | 金色（こんじき／金） |
| `orange` | 柑子（こうじ／オレンジ） |
| `sakura` | 桜（さくら／ピンク） |
| `red` | 朱（あけ／赤） |
| `wine` | 蘇芳（すおう／赤紫） |
| `purple` | 藤（ふじ／紫） |
| `brown` | 焦茶（こげちゃ／茶） |
| `neutral` | 銀鼠（ぎんねず／灰色） |
| `dark` | 墨色（すみいろ／黒） |

### 3.2 言語（`lang`）

HTML ドキュメントの `lang` にそのまま入ります。よく使う値は `ja`（日本語）、`en`（英語）などです。`ja-JP` のような詳細なタグも入力できます。

言語を変えても、本文フォントや組版の自動切替は行われません。フォントは「フォント・体裁」タブで別に指定します。

## 4. 表紙タブ

### 4.1 表紙の構成（画面プレビューと同じ）

表紙を付ける場合、用紙上の配置は次のとおりです（上から下へ）。

| 要素 | 設定項目 | 位置 |
|------|----------|------|
| ラベル | `label` | 上部の小さな枠（番号・区分など） |
| タイトル | `title` | 中央の大きな見出し |
| サブタイトル | `subtitle` | タイトル直下の副題 |
| 表紙フッタ | `meta`（複数行可） | ページ下端（発行元・日付など） |
| 著者／版／日付 | `author` / `version` / `date` | メタ。`meta` が空のときは表紙フッタへ自動流し込み。ヘッダ／フッタの定型にも使える |

ドキュメント設定画面の右側に、同じ配置のプレビューが表示されます。各欄の近くに「ラベル」「タイトル」などの役割表示が出ます。

「表紙を付ける」をオフにすると、PDF は本文から始まります。

### 4.2 表紙デザイン（`coverPattern`）

色テーマごとに用意された背景デザインを選びます。画像が無い組み合わせでは、色テーマの単色（またはグラデーション）で表示されます。

代表的な値と表示名:

| 値 | 表示名 | 値 | 表示名 |
|----|--------|----|--------|
| `noise` | 霞 | `grainy` | 砂子 |
| `aurora` | 極光 | `mesh` | 彩雲 |
| `solid` | 無地 | `diagonal` | 斜影 |
| `horizontal` | 横霞 | `vertical` | 縦霞 |
| `radial` | 円暈 | `split` | 二面 |
| `band` | 帯 | `corner` | 隅取り |
| `ribbon` | 側帯 | `panel` | 脇板 |
| `frame` | 額縁 | `glow` | 中暈 |
| `dusk` | 黄昏 | `mist` | 薄霧 |
| `horizon` | 地平 | `stripe` | 縦縞 |
| `dots` | 点描 | `grid` | 方眼 |
| `chevron` | 矢筈 | `diamond` | 菱 |
| `hex` | 亀甲 | `triangle` | 鱗 |
| `checker` | 市松 | `herringbone` | 杉綾 |
| `isometric` | 升目 | `lattice` | 組子 |
| `mosaic` | 寄木 | `blades` | 切子 |
| `sunburst` | 日輪 | `spiral` | 渦 |
| `orbit` | 周回 | `circles` | 同心円 |

一覧はドキュメント設定画面の「表紙デザイン」でも同じ名称で選べます。

## 5. フォント・体裁タブ

### 5.1 本文フォント（`font`）

組み合わせ（和文／欧文の優先ファミリー）を選びます。画面にはファミリー名と見本だけ出ます。

| 値 | 和文（優先） | 欧文（優先） |
|----|--------------|--------------|
| `noto` | Noto Sans JP | Segoe UI |
| `gothic` | 游ゴシック／ヒラギノ角ゴ／Noto Sans JP | Segoe UI |
| `mincho` | Noto Serif JP／游明朝／ヒラギノ明朝 | 同左 |
| `sans` | Noto Sans JP | Segoe UI／system-ui |
| `serif` | Noto Serif JP | Georgia／Times New Roman |
| `inter` | Noto Sans JP | Inter |
| `mono` | IBM Plex Mono | IBM Plex Mono |

「カスタム」に値を入れると、上の選択より優先されます。

### 5.2 コードフォント（`fontMono`）

インラインコード、コードブロック、図のソース表示に使います。本文フォントとは独立です。

| 画面上の選択 | 実際のフォント（要約） |
|--------------|------------------------|
| Cascadia / Consolas（既定） | Cascadia Mono → Consolas → Courier New |
| IBM Plex Mono | IBM Plex Mono を優先 |
| Consolas | Consolas → Courier New |
| カスタム | 入力した CSS の `font-family` |

### 5.3 その他の体裁

| 項目 | 説明 | 既定の目安 |
|------|------|------------|
| 用途プリセット | 標準／報告書／スライド資料寄り（サイズ・行間・字間を一括） | （任意） |
| 文字サイズ | 本文の基本サイズ（例: `10.5pt`） | `10.5pt` |
| 行間 | 倍率（例: `1.7`） | `1.7` |
| 字間 | CSS `letter-spacing`（例: `0` / `0.02em`） | `0` |
| 角丸 | コードブロックや表などの角 | オン、サイズ「中」 |
| 見出し帯背景 | 第 2 水準見出しに色テーマの帯を付ける | オン |
| 表ヘッダ塗りつぶし | 表のヘッダ行を色テーマの濃色で塗る | オン |
| リンク下線 | `linkUnderline` | オフ |
| リンク色をテーマに | `linkThemeColor`（オフなら本文色） | オン |

## 6. 用紙・余白タブ

| 項目 | キー | 値の例 |
|------|------|--------|
| 用紙サイズ | `pageSize` | `a4`（既定）/ `a5` / `b5` / `letter` |
| 向き | `pageOrientation` | `portrait`（既定）/ `landscape` |
| 余白 | `marginPreset` | `narrow` / `normal`（既定）/ `wide` / `custom` |
| 余白 mm | `marginTop` など | `custom` のときのみ（単位なし数値＝mm） |

プレビューの用紙サイズと PDF の紙面は連動します。

---

## 7. ページ・コードタブ

### 7.1 本文ヘッダ／フッタ

表紙フッタ（`meta`）とは別枠です。

| 項目 | キー | 定型 |
|------|------|------|
| ヘッダ | `pageHeader` | なし／文書名／著者／日付／版／社外秘／カスタム |
| フッタ | `pageFooter` | なし／ページ番号／文書名／文書名＋ページ番号／日付／著者／社外秘／カスタム |

既定はどちらも「なし」。PDF では全ページ（表紙含む）に出ます。プレビューでは本文ページのみです。

### 7.2 目次

| 項目 | キー | 説明 |
|------|------|------|
| 自動目次 | `toc` | オンで本文に `[TOC]` が無いとき先頭へ挿入 |
| 深さ | `tocDepth` | `2`（H2 まで）または `3`（H3 まで、既定） |

手書きの `[TOC]` もそのまま使えます（深さ設定は効きます）。目次は**前後とも改ページ**され、プレビュー／PDF とも専用ページ（長いときは複数頁）になります。

### 7.3 コードブロック

| 項目 | キー | 既定 |
|------|------|------|
| 行番号 | `codeLineNumbers` | オフ |
| 折り返し | `codeWrap` | オフ（横スクロール） |
| 文字サイズ | `codeFontSize` | 空＝本文連動（約 0.92em） |

### 7.4 透かし

| 項目 | キー | 値 |
|------|------|-----|
| 種類 | `watermark` | `none` / `draft` / `confidential` / `custom` |
| 文言 | `watermarkText` | `custom` のとき |

## 8. ドキュメント先頭に書き込まれる形

「適用」後、ドキュメントの先頭は次のような形になります（例）。

```yaml
---
ohyna:
  title: ドキュメントタイトル
  style: blue
  font: noto
  lang: ja
  cover: true
  subtitle: 副題
  label: DOC
  meta:
    - 発行元
    - 2026-07
---
```

規則の要点:

- 設定は必ず `ohyna:` の下に置きます。  
- キー名は camelCase です（例: `coverPattern`、`fontSize`）。  
- このブロックのあとに、通常の Markdown 本文が続きます。  

通常はドキュメント設定画面から編集すれば足り、手編集は不要です。
