# 確認と PDF 出力

本章では、自動の内容チェック、プレビュー、PDF の作成と保存までを説明します。

---

## 1. 内容の自動チェック

編集を少し止めると（おおよそ 0.5 秒）、内容が自動で検査されます。結果は次の場所に出ます。

| 場所 | 内容 |
|------|------|
| 下部のコンソール | 「✔ Markdown」など。アイコンが結果を表す。クリックで「問題」タブ |
| 下部の「問題」タブ | 各行は「12行目: メッセージ」の形。行をクリックするとその場所へ移動 |
| エディタ本文 | 該当行の波線と、行番号横の印。ホバーでメッセージ。F8 で次の問題へ |
| 下部の「出力」 | エラーがあるあいだ「問題 N 件のためプレビューを更新できません」など。詳細に同じ「N行目: …」 |

プレビューが本文と揃っているかも、同じコンソールに「✔ プレビュー」などと出ます（アイコンが状態。ペイン右上には出しません）。

### 1.1 検査結果とできること

| 結果 | プレビューの更新 | PDF 生成 |
|------|------------------|----------|
| エラー（error）が 1 件以上 | しない（直前の表示を維持し「未更新」） | できない |
| 注意（warning）のみ、または指摘なし | できる | できる |
| 確認処理中 | 待つ | 待つ |

### 1.2 何を検査するか

| 区分 | 内容 |
|------|------|
| ドキュメント設定 | `ohyna:` の有無、必須項目（タイトル・色テーマ・フォント・言語）、色・フォント・角丸・表紙デザインの値の妥当性 |
| Markdown の構造 | コードフェンスの閉じ忘れ、見出しの書き方、空のリンク／画像、数式の区切りの対応など |
| コードフェンス | ハイライト可能な言語名か。`json` / `yaml` のときは内容の構文も確認 |
| Mermaid ダイアグラム | 言語名 `mermaid` のフェンスを、PDF と同じ描画経路で実際に描けるか |
| 数式 | `$` / `$$` / 数式フェンスなどを、PDF と同じ KaTeX 設定で描けるか |

エラーが出ているあいだは、プレビューを新しい内容に更新できず、PDF も生成できません。表示されているメッセージに従って直してください。

---

## 2. プレビュー

右ペインは A4（210 × 297 mm）の用紙イメージです。PDF ビューアではなく、HTML で近似表示しています。

### 2.1 できる操作・できない操作

| 操作 | 可否 | 説明 |
|------|------|------|
| ズーム・スクロール・用紙への合わせ込み | 可 | 表示倍率と見え方だけが変わる。ドキュメントの組版状態は変えない |
| リンクを開く | 不可 | 見た目確認のみ（ジャンプしない） |
| 折りたたみの開閉 | 不可 | 常に展開。PDF と同じ見た目 |
| タスクのチェック切替 | 不可 | 表示のみ |
| 別ウィンドウ表示 | 可 | プレビューだけを別ウィンドウに出せる（コンソールも同様に外だし可） |

### 2.2 更新のしかた

- 検査が通っているあいだ、編集内容に追随して更新されます。  
- ヘッダの更新ボタンで、明示的に再取得できます。  
- 検査エラー中は更新されず「未更新」になります。  

### 2.3 プレビューと PDF の違い

| 項目 | プレビュー | PDF |
|------|------------|-----|
| 役割 | 編集中の確認 | 配布・印刷の基準 |
| ページの区切り | 画面上の近似 | Chromium による印刷結果 |
| 図（Mermaid） | ブラウザで描画 | サーバで SVG にして埋め込み |
| 数式 | ブラウザの KaTeX | 同じ区切り・同じ方針で描画 |

ページ番号や改ページ位置の最終確認は、必ず PDF 確認画面で行ってください。

### 2.4 用紙と余白（成果物の仕様）

| 項目 | 値 |
|------|-----|
| 用紙 | A4（210 × 297 mm） |
| 本文の余白 | 上 14 mm、右 14 mm、下 16 mm、左 14 mm |
| 表紙 | 余白なし（用紙全面） |

## 3. PDF の生成と保存

「PDFを作成」は、編集内容を成果物として実行する操作です（IDE のデバッグ実行に近い位置づけ）。問題や設定不足があるときはモーダルを強制せず、下部の「出力」に理由が出ます。

### 3.1 手順

1. ヘッダの「PDFを作成」を押す（処理中は進行表示になる）。  
2. 問題やドキュメント設定の不足があるときは作成できず、下部の「出力」に内容が出る。直してから再度押す。  
3. 成功すると「PDF確認」画面が開く。  
4. 内容を確認し、「PDFを保存」でファイルへ書き込むか、「印刷」で OS の印刷ダイアログを開く。  

同じ本文からすでに生成済みの PDF がある場合は、再生成せず確認画面を開くことがあります。本文を変えると、そのキャッシュは無効になります。

### 3.2 保存と印刷

| 操作 | 内容 |
|------|------|
| PDFを保存 | OS の保存ダイアログで保存先を選ぶ（「ダウンロード」という名称の操作はない） |
| 印刷 | 生成済み PDF を OS の印刷ダイアログへ渡す（プリンタ／PDF プリンタなど） |

### 3.3 表紙について

ドキュメント設定で表紙を有効にしている場合、PDF の先頭に表紙ページが付きます。タイトル・サブタイトル・ラベル・フッタの位置は「ドキュメント設定」の章で説明した配置と同じです。

## 4. 別ウィンドウのプレビュー

| ウィンドウ | 表示 |
|------------|------|
| メインウィンドウ（元の画面） | エディタのみ（全幅） |
| 子（別ウィンドウ） | プレビューのみ（メインが生成した内容を同期） |

メインウィンドウから、子を前面に出す操作と、プレビューをメインへ戻して子を閉じる操作ができます。子を閉じると、プレビューはメイン側に戻ります。

コンソールも同様に、バー右端のウィンドウアイコンから別ウィンドウへ外だしできます。外だし中はメイン下部に細いバーが残り、前面へ／戻すが使えます。問題一覧からの行ジャンプはメインのエディタ側へ届きます。
