# 表紙背景アセット

`{style}/{pattern}.webp` — `style` × `coverPattern` で選ぶ静的背景画像。

実行時はこれを `<img class="cover-bg">` として表紙に挿入する。模様の変更は画像の差し替えで行う。

## 出所とライセンス

本ディレクトリの WebP は **本プロジェクト向けに生成したオリジナル画像**です（第三者ストック素材の取り込みではありません）。  
リポジトリ全体と同じ [MIT License](../../LICENSE) で提供します。

`manifest.json` の `dir` はリポジトリ相対パスのみを記録します（マシン固有の絶対パスを書かないこと）。

詳細は `docs/spec/07-開発者ガイド.md` / `docs/spec/05-印刷とプレビュー.md`。
