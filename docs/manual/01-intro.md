# はじめに

**Ohyna**（Open Hybrid Note App／おひな）は、Ohyna Markdown（Markdown を基礎とした本製品のドキュメント形式）で書いたドキュメントを A4 判の PDF に仕上げるための製品です。画面上で編集し、印刷に近いプレビューで体裁を確認したうえで、配布用の PDF を保存します。

本マニュアルは画面の「ヘルプ」から読む利用者向けの説明です。各章は必要な説明をその場で完結させています。仕様の詳細は同じヘルプ内の「仕様書」、許諾は「ライセンス」を参照してください。

---

## 1. できること

| 用途 | 内容 |
|------|------|
| ドキュメントの編集 | Markdown 本文とドキュメント設定（表紙・色・フォントなど）を画面で編集する |
| ファイルの読み書き | 一般的なデスクトップアプリと同様に、開く・保存・名前を付けて保存ができる |
| 品質チェック | 編集内容を自動検査し、問題があるあいだはプレビュー更新や PDF 生成を止める |
| プレビュー | A4 用紙イメージで体裁・図・数式を確認する（見た目を変える操作はできない） |
| PDF の作成 | 検査を通過したドキュメントから PDF を生成し、確認のうえファイルへ保存する |

本製品の画面が扱うのは、**1 つの Markdown ドキュメントから 1 つの PDF を作る**作業です。

---

## 2. 成果物の考え方

| 成果物 | 位置づけ |
|--------|----------|
| 画面のプレビュー | 編集中の確認用。ページの区切り位置は近似です |
| PDF | **配布・印刷の基準**。最終確認は PDF 確認画面で行います |

プレビューと PDF で共通なのは、本文の解釈・表紙の文言・色テーマ・フォント・数式・図のソースです。プレビューだけでページ割を確定させないでください。

---

## 3. 標準の作業の流れ

1. **作成または開く** — 空のドキュメント（必須設定済みの無題）／サンプルから作成するか、既存ファイルを開く  
2. **ドキュメント設定** — 必要ならタイトルや色などを変え、「適用」する  
3. **本文を書く** — Markdown で本文を編集する（次章以降の記法に従う）  
4. **保存** — ファイルメニューの「保存」または「名前を付けて保存…」でディスクへ書き込む  
5. **検査を確認** — 下部のコンソールが「✔ Markdown」「✔ プレビュー」であることを確認する（注意のみなら警告アイコン）  
6. **プレビュー** — 右ペインで体裁を確認する  
7. **PDFを作成** — 確認画面で内容を見て「PDFを保存」または「印刷」する  
8. **閉じる** — 編集を終えるときはファイルメニューの「閉じる」（ディスク上のファイルは削除しない）  
 

「ドキュメント設定」の「適用」は、編集中のドキュメントデータ（先頭の設定ブロック）へ反映する操作です。ディスク上のファイルへの書き込みは、必ず「保存」で行います。

## 5. 利用上の前提

- 本画面は、組織などが用意した **サーバ上のサービス** としてブラウザから使います。  
- 利用者が確認できる説明は **この画面のヘルプに載っている内容だけ** です（外部の開発用サイトやリポジトリを見る前提はありません）。  
- 編集・プレビュー・PDF 生成のため、入力内容は接続先のサービスへ送られます。パスワードや秘密鍵などは貼り付けないでください。  
- ディスクへの保存の要否、他者との共有、データの保持期間は、**サービス提供者の案内**に従ってください。  
- 不具合や問い合わせは、このサービスを提供している組織の窓口へ連絡してください。  
- 受け取った Markdown を開くときは、内容を確認してからにしてください。
