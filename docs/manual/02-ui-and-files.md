# 画面とファイル操作

本章では、画面の構成と、ファイルの開く・保存の操作を説明します。

---

## 1. 画面の構成

画面は次の領域で構成されます。

| 領域 | 役割 |
|------|------|
| ヘッダ左 | 製品名、現在のドキュメント名（未保存のときは先頭に「●」） |
| ヘッダ中央〜右寄り | 表示の明るさ、ヘルプ（マニュアル／仕様書／ライセンス） |
| ヘッダ右 | ファイルメニュー、プレビューを更新、PDFを作成 |
| 左ペイン | Markdown 編集、編集ツールバー（本文の波線）、ドキュメント設定ボタン |
| 右ペイン | A4 相当のプレビュー（拡大縮小・別ウィンドウ） |
| 下部 | コンソール（検査・プレビューの現在状態と、問題一覧／出力）。境界をドラッグして高さを変えられる |
| モーダル | ドキュメント設定、PDF 確認、未保存の確認、ヘルプ |

短いお知らせは画面上部中央から表示されます。エラーや注意の詳細は下部の「出力」に残ります。

### 1.2 下部のコンソール（IDE のパネルに相当）

編集領域との境界をドラッグして高さを変えられます。折りたたみ中でも、次の現在状態が常に見えます。

| 表示 | 意味 |
|------|------|
| ✔ Markdown / ✖ Markdown など | 左のアイコンが検査結果（✔問題なし／⚠注意／✖問題／…）。クリックで「問題」一覧 |
| ✔ プレビュー / ⚠ プレビュー など | 左のアイコンがプレビュー状態（✔最新／⚠未更新／✖エラー／…）。ホバーで詳細 |
| 最新のメッセージ（折りたたみ時） | 「出力」の先頭行。クリックで「出力」を開く |
| ウィンドウアイコン | コンソールだけを別ウィンドウへ外だし（戻す／前面へも可） |

パネルを開くとタブが分かれます。

| タブ | 内容 |
|------|------|
| 問題 | 検査結果の一覧（「12行目: …」）。行をクリックするとその場所へ移動 |
| 出力 | 保存やエラーなどの履歴（区分・見出し・詳細・時刻） |

「出力」の件数バッジはエラー（赤）と注意（橙）です。ゴミ箱アイコンで履歴だけ消えます（検査・プレビューの状態表示は消えません）。外だし中も履歴はメインウィンドウと同期します。

ドキュメント名が表示されていないときは「無題」です。一度も保存していない新規編集も「無題」と表示されます。

### 1.1 起動時に開くドキュメント

| 状況 | 起動時の内容 |
|------|----------------|
| 初めて使う（まだ一度も開く・保存・新規をしていない） | 記法の説明用サンプル |
| 前回、ファイルを開いた／保存した（対応ブラウザ） | そのファイル（続きから編集） |
| 前回のファイルの権限がまだ無い | 空の無題で開始。「前回のファイルを開く」を押して許可する（起動だけでは権限を求めない） |
| 前回のファイルが削除・移動されている | 空の無題。短い通知が出る |
| 前回「新規」のまま終了したなど | 空の無題 |

起動のたびにファイル選択画面は出ません。開くときはメニューの「開く…」を使います。

---

## 2. ファイルメニュー（ドキュメントの CRUD）

ヘッダのフォルダアイコンから、ドキュメントの作成・読み込み・書き込み・終了ができます。

| 区分 | メニュー | ショートカット（Windows） | ショートカット（macOS） | 動作 |
|------|----------|---------------------------|-------------------------|------|
| 作成 | 空のドキュメント | — | — | 必須設定入りの無題ドキュメントを作成する（検査エラーにならない状態） |
| 作成 | サンプルから作成 | — | — | 記法説明用サンプルで新規作成する |
| 読み込み | 開く… | Ctrl+O | ⌘+O | ファイルを選んで開く。ドラッグ＆ドロップでも同じ |
| 書き込み | 保存 | Ctrl+S | ⌘+S | いまのファイルへ上書きする。場所が無いときは「名前を付けて保存…」と同じ |
| 書き込み | 名前を付けて保存… | Ctrl+Shift+S | ⌘+Shift+S | 保存先とファイル名を指定して書き込む |
| 終了 | 閉じる | — | — | 編集を終え、空の無題ドキュメントに戻す |

対応ブラウザでは、OS 標準のファイルダイアログでディスク上のファイルを直接読み書きします。ブラウザがこの方式に対応していない場合も、同じメニュー名で保存操作ができます。前回ファイルの自動復元は、この直接読み書きに対応したブラウザで有効です。

### 2.1 操作の流れ

```text
作成（空／サンプル） ──┐
開く／ドロップ ────────┼─→ 編集 ─→ 保存／名前を付けて保存
閉じる ────────────────┘         └─→ PDFを作成（別操作）
```

- **作成**: いまの編集を終えて新しいドキュメントにする  
- **読み込み**: ディスク上の Markdown を編集対象にする  
- **書き込み**: 編集中の全文をファイルへ残す  
- **閉じる**: ファイルとの関連を外し、空の無題に戻す（ディスク上のファイルは削除しない）

未保存の変更がある状態で作成・読み込み・閉じるを行うと、次の確認が出ます。

| 選択 | 動作 |
|------|------|
| 保存 | いまの内容を保存してから、選んだ操作を続ける |
| 保存しない | 変更を捨てて、選んだ操作を続ける |
| キャンセル | 何もせず編集に戻る |

「開く…」は、先にファイル選択を出してから未保存確認します（ブラウザの制約のため）。キャンセルすると選択したファイルは開きません。

### 2.2 未保存の見え方

| 状況 | 動作 |
|------|------|
| 内容が最後の保存時と異なる | ドキュメント名が琥珀色のチップになり「未保存」と点で示される。ヘッダ下線とファイルボタンも同色になる。ウィンドウタイトル先頭に「●」が付く |
| 未保存のままブラウザのタブやウィンドウを閉じる | ブラウザ標準の離脱確認が出ることがある |

### 2.3 「適用」と「保存」の違い

| 操作 | 何が変わるか |
|------|----------------|
| ドキュメント設定の「適用」 | 編集中のドキュメント先頭にある設定ブロック（`ohyna:`）を更新する。ディスクには書かない |
| ファイルの「保存」 | 編集中の全文（設定ブロックと本文）をファイルへ書き込む |

設定を変えたあとは、必要に応じて「保存」でファイルへ反映してください。

## 3. 編集ツールバーとショートカット

左ペイン上部のツールバーから、強調・見出し・リスト・リンク・数式・コード・表・折りたたみ・キーボードキー表記などを挿入できます。

主なショートカット:

| 操作 | Windows | macOS |
|------|---------|-------|
| 太字 | Ctrl+B | ⌘+B |
| 斜体 | Ctrl+I | ⌘+I |
| 打消し | Ctrl+Shift+X | ⌘+Shift+X |
| インラインコード | Ctrl+E | ⌘+E |
| リンク | Ctrl+K | ⌘+K |
| インライン数式 | Ctrl+Shift+M | ⌘+Shift+M |
| 見出し 1〜6 | Ctrl+Alt+1〜6 | ⌘+⌥+1〜6 |
| 箇条書き | Ctrl+Shift+8 | ⌘+Shift+8 |
| 番号付きリスト | Ctrl+Shift+7 | ⌘+Shift+7 |
| タスクリスト | Ctrl+Shift+9 | ⌘+Shift+9 |
| 引用 | Ctrl+Shift+. | ⌘+Shift+. |
| 整形（行末空白の整理など） | Ctrl+Shift+L | ⌘+Shift+L |

画面上のツールチップは、いまの OS に合わせて Ctrl または ⌘ で表示されます。

## 4. ドキュメント設定を開く

左ペインの「ドキュメント設定」から、表紙・色テーマ・フォントなどを編集します。必須はタイトル・色テーマ・フォント・言語の 4 つです。揃っていないあいだはプレビューの更新と PDF 生成ができません。色テーマは表紙だけでなく見出し帯・表・図にも効きます。各項目の選択肢と表紙の配置は、本マニュアルの「ドキュメント設定」の章に一覧があります。

「空のドキュメント」や「閉じる」で始まる無題には、あらかじめ必須 4 項目（タイトル「無題」・色テーマ・フォント・言語）が入っています。設定画面は自動では開きません。設定が足りないときは下部の「問題」と「出力」に出ます（「PDFを作成」や保存を実行したときも同様）。直すときは自分で「ドキュメント設定」を開きます。

## 5. プレビューの基本操作

| 操作 | Windows | macOS |
|------|---------|-------|
| 拡大・縮小 | Ctrl+マウスホイール、またはズームボタン | ⌘+マウスホイール、またはズームボタン |
| 表示位置の移動 | マウス中ボタンのドラッグ | 同左 |
| 用紙への合わせ込み | プレビューツールバーの「全体に収める／幅に合わせる／高さに合わせる」 | 同左 |
| 別ウィンドウ | プレビュー領域のウィンドウアイコン。子ウィンドウはプレビューのみ、メインウィンドウはエディタ全幅 | 同左 |

プレビューは成果物の見た目確認用です。折りたたみの開閉、タスクのチェック切替、リンクのジャンプなど、**ドキュメントを操作する行為はできません**。表示倍率・スクロールのみ可能です。

問題があるとプレビューは更新されず、PDF も作成できません。PDF はヘッダの「PDFを作成」で作り、確認画面の「PDFを保存」でファイルへ書き込みます。詳しい手順は本マニュアルの「確認と PDF 出力」の章にあります。
