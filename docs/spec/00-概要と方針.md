# 00. 概要と方針

## 1. 製品

**Ohyna**（Open Hybrid Note App／おひな、版 1.0.0）は、日本語を主対象としたドキュメントを Markdown から **印刷品質の PDF** に仕上げるサービスです。本画面のヘルプから読む方は、ブラウザ上で文書を編集・確認・PDF 保存する利用者です。

製品の利用面は **単一文書**です。1 つの Markdown を編集し、1 つの PDF を出力します（GUI、および同じ契約の HTTP `POST /preview`・`/pdf`・`/analyze`、CLI `pdf` / `serve`）。

できること（この画面）:

| 用途 | 内容 |
|------|------|
| 編集 | Markdown 本文とドキュメント設定（表紙・色・フォントなど） |
| 検査 | 問題があるあいだはプレビュー更新や PDF 生成を止める |
| プレビュー | 用紙イメージで体裁・図・数式を確認する |
| PDF | 検査通過後に生成し、確認のうえ保存する |

---

## 2. 設計の骨子（利用者向け）

1. **文書形式は Ohyna Markdown**（Markdown を基礎とした製品プロファイル。CommonMark／GFM の完全準拠は標榜しない）
2. **図は Mermaid**（`mermaid code` はコード表示）
3. **数式は KaTeX**（`$...$` / `$$...$$` など、および math 系フェンス）
4. **体裁はドキュメント先頭の設定**（`ohyna:`）で定義する
5. **検査で error があるあいだは、プレビュー更新と PDF 生成を進めない**
6. **プレビューは確認用の近似、配布・印刷の基準は PDF**

---

## 3. 想定する使い方

- 手順書、仕様書、報告書を Markdown で書き、PDF で配布する
- 画面で体裁を確認しながら 1 文書を仕上げる

この画面だけではできないこと（組織の運用・提供形態による）:

- サーバの構築や公開設定の変更
- 他利用者への自動共有（保存や共有のルールは、サービス提供者の案内に従う）

---

## 4. 利用上の前提

| 項目 | 内容 |
|------|------|
| 提供形態 | 組織などが用意したサーバ上のサービスとして、ブラウザから利用する |
| 必須のドキュメント設定 | タイトル、色テーマ、本文フォント（またはカスタム）、言語 |
| 最終確認 | 画面プレビューではなく **PDF 生成後の確認** |
| データの扱い | 編集・プレビュー・PDF 生成のため、入力は接続先のサービスへ送られる。秘密情報の貼り付けは控える |
| 不具合・問い合わせ | この画面の提供者（組織の窓口）へ。本ヘルプ外のサイトを前提にしない |
