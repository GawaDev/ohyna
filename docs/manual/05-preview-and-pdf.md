# 確認と PDF 出力

---

## 1. 内容の検査

編集を少し止めると（おおよそ 0.5 秒）、内容が自動で検査されます。結果は次の場所に出ます。

| 場所 | 内容 |
|------|------|
| コンソール | 「✔ Markdown」など。アイコンが結果を表す。クリックで「問題」タブ（狭い画面では画面上部の「コンソール」タブ） |
| 「問題」タブ | 各行は「12行目: メッセージ」の形。行をクリックするとその場所へ移動 |
| エディタ本文 | 該当行の波線と、行番号横の印。ホバーでメッセージ。F8 で次の問題へ |
| 「出力」タブ | 問題があるあいだ「問題 N 件のためプレビューを更新できません」など。詳細に同じ「N行目: …」 |

プレビューが本文と揃っているかも、同じコンソールに「✔ プレビュー」などと出ます（アイコンが状態）。

### 1.1 検査結果とできること

| 結果 | プレビューの更新 | PDFを作成 |
|------|------------------|-----------|
| 問題（error）が 1 件以上 | 直前の表示を維持（「未更新」）。直すと更新できる | 問題を直すと作成できる |
| 注意（warning）のみ、または指摘なし | できる | できる |
| 確認処理中 | 終わるまで待つ | 終わるまで待つ |

### 1.2 何を検査するか

| 区分 | 内容 |
|------|------|
| ドキュメント設定 | `ohyna:` の有無、必須項目（タイトル・色テーマ・フォント・言語）、色・フォント・角丸・表紙デザインの値の妥当性 |
| Markdown の構造 | コードフェンスの閉じ忘れ、見出しの書き方、空のリンク／画像、数式の区切りの対応など |
| コードフェンス | ハイライト可能な言語名か。`json` / `yaml` のときは内容の構文も確認 |
| Mermaid ダイアグラム | 言語名 `mermaid` のフェンスを、PDF と同じ描画経路で実際に描けるか |
| 数式 | `$` / `$$` / 数式フェンスなどを、PDF と同じ KaTeX 設定で描けるか |

表示されている問題に従って直してください。

## 2. プレビュー

右ペインは A4（210 × 297 mm）の用紙イメージです。

### 2.1 プレビューでできること

| 操作 | 説明 |
|------|------|
| ズーム・スクロール・用紙への合わせ込み | 表示倍率と見え方だけが変わる。ドキュメントの組版状態は変えない。ピンチ、Ctrl／⌘＋ホイール、ツールバーでも拡大縮小できる |
| 見た目の確認 | リンク・折りたたみ・タスクは成果物と同じ見た目で表示する（折りたたみは常に展開） |
| 別ウィンドウ表示 | プレビューだけを別ウィンドウに出せる（コンソールも同様に外だし可） |

### 2.2 更新のしかた

- 検査が通っているあいだ、編集内容に追随して更新されます。  
- ヘッダの「プレビューを更新」で、明示的に再取得できます。  
- 問題があるあいだは「未更新」のままです。問題を直すと更新できます。  

### 2.3 プレビューと PDF

| 項目 | プレビュー | PDF |
|------|------------|-----|
| 役割 | 編集中の確認 | 配布・印刷の基準 |
| ページの区切り | 画面上の近似 | Chromium による印刷結果 |
| 図（Mermaid） | ブラウザで描画 | サーバで SVG にして埋め込み |
| 数式 | ブラウザの KaTeX | 同じ区切り・同じ方針で描画 |

ページ番号や改ページ位置の最終確認は、PDF 確認画面で行います。

### 2.4 用紙と余白

用紙サイズ・向き・余白はドキュメント設定の「用紙・余白」で指定します（既定は A4 縦）。プレビューの用紙と PDF の紙面は連動します。表紙ページは用紙全面を使います。

## 3. PDF の生成と保存

「PDFを作成」は、編集内容を成果物として実行する操作です。問題や設定不足があるときはモーダルを強制せず、コンソールの「出力」に理由が出ます。

### 3.1 手順

1. ヘッダの「PDFを作成」を押す（処理中は進行表示になる）。  
2. 問題やドキュメント設定の不足があるときは、コンソールの「出力」に内容が出る。直してから再度押す。  
3. 成功すると「PDF確認」画面が開く。  
4. 内容を確認し、「PDFを保存」でファイルへ書き込むか、「印刷」で OS の印刷ダイアログを開く。  

同じ本文からすでに生成済みの PDF がある場合は、再生成せず確認画面を開くことがあります。本文を変えると、そのキャッシュは無効になります。

### 3.2 保存と印刷

| 操作 | 内容 |
|------|------|
| PDFを保存 | OS の保存ダイアログで保存先を選ぶ |
| 印刷 | 生成済み PDF を OS の印刷ダイアログへ渡す（プリンタ／PDF プリンタなど） |

### 3.3 表紙について

ドキュメント設定で表紙を有効にしている場合、PDF の先頭に表紙ページが付きます。タイトル・サブタイトル・ラベル・フッタの位置は「ドキュメント設定」の章と同じ配置です。

## 4. 別ウィンドウのプレビュー

| ウィンドウ | 表示 |
|------------|------|
| メインウィンドウ（元の画面） | エディタのみ（全幅） |
| 子（別ウィンドウ） | プレビューのみ（メインが生成した内容を同期） |

メインウィンドウから、子を前面に出す操作と、プレビューをメインへ戻して子を閉じる操作ができます。子を閉じると、プレビューはメイン側に戻ります。

コンソールも同様に、バー右端のウィンドウアイコンから別ウィンドウへ外だしできます。外だし中はメイン側に細いバーが残り、前面へ／戻すが使えます。問題一覧からの行ジャンプはメインのエディタ側へ届きます。
