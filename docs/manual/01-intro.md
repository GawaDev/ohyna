# はじめに

**Ohyna**（Open Hybrid Note App／おひな）は、Ohyna Markdown の文書を PDF にするオープンソースです。ブラウザで編集し、プレビューで体裁を確かめてから PDF を保存します。

---

## 1. 機能

| 用途 | 内容 |
|------|------|
| 文書の編集 | Markdown 本文とドキュメント設定（表紙・色・フォントなど）を編集する |
| ファイル操作 | 開く・保存・名前を付けて保存 |
| 内容の検査 | 問題があるあいだはプレビュー更新と PDF 作成を止める |
| プレビュー | 用紙イメージで体裁・図・数式を確認する |
| PDF の作成 | 検査を通過した文書から PDF を生成し、確認のうえ保存する |

扱う単位は **1 つの Markdown 文書から 1 つの PDF** です。

---

## 2. 成果物の位置づけ

| 成果物 | 位置づけ |
|--------|----------|
| 画面のプレビュー | 編集中の確認用。ページ区切りは近似 |
| PDF | 配布・印刷の基準。最終確認は PDF 確認画面で行う |

本文の解釈、表紙の文言、色テーマ、フォント、数式、図のソースはプレビューと PDF で共通です。ページ割の確定は PDF で行います。

---

## 3. 標準の作業手順

1. **作成または開く** — 無題の新規文書／サンプルから始めるか、既存ファイルを開く  
2. **ドキュメント設定** — タイトルや色などを変更し、「適用」する  
3. **本文を書く** — Markdown で編集する  
4. **保存** — 「保存」または「名前を付けて保存…」でディスクへ書き込む  
5. **検査を確認** — コンソールが「✔ Markdown」「✔ プレビュー」であること（注意のみの場合は警告表示）  
6. **プレビュー** — 右ペインで体裁を確認する  
7. **PDFを作成** — 確認画面で内容を見て「PDFを保存」または「印刷」する  
8. **閉じる** — 「閉じる」で空の無題に戻る（ディスク上のファイルはそのまま）

「適用」は文書先頭の設定ブロックへの反映、「保存」はディスクへの書き込みです。

## 5. 利用上の前提

- 組織のサーバまたは公開デモを、ブラウザから利用します。  
- 説明は画面ヘルプに掲載された内容です。  
- 編集・プレビュー・PDF 作成のため、入力は接続先サービスへ送られます。秘密情報は入力しないでください。  
- 保存・共有・保持期間は、サービス提供者の案内に従います。  
- 不具合・改善は [GitHub Issues](https://github.com/GawaDev/ohyna/issues)、運用環境のことはサービス提供者へ。  
- 受け取った Markdown は、開く前に内容を確認してください。
