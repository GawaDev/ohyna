# 07. 開発者ガイド

ソース: [https://github.com/GawaDev/ohyna](https://github.com/GawaDev/ohyna)  
公開デモ: [https://ohyna.onrender.com/](https://ohyna.onrender.com/)

## 1. 開発環境

利用者向け画面ヘルプ（`_DOCS_CATALOG`）にはセットアップ手順・本ガイド・アーキテクチャ／API／セキュリティ詳細を載せません。ヘルプはデプロイ先の利用者が読める唯一の説明面です。構築・起動は本節に従ってください。

```bash
cd ohyna
pip install -r requirements.txt
python -m playwright install chromium

cd web
npm install
```

| 用途 | コマンド |
|------|----------|
| API + ビルド済み GUI | `python -m ohyna serve --host 127.0.0.1 --port 8787` |
| GUI ホットリロード | `cd web && npm run dev`（Vite。API は `8787` へ proxy） |
| GUI 本番ビルド | `cd web && npm run build` → `gui/` |

開発ブラウザ: `http://127.0.0.1:8787/`  
本番公開はリバースプロキシ配下（[06-セキュリティ.md](./06-セキュリティ.md)）。別オリジンが必要なら `OHYNA_ALLOWED_ORIGINS`。

Python パッケージはリポジトリルートを `PYTHONPATH` に含めるか、同ディレクトリで `python -m ohyna` を実行します。

## 2. ディレクトリと責務

| パス | 触るとき |
|------|----------|
| `ohyna/pdf.py` | Markdown 変換、bleach、プレビュー／PDF HTML |
| `ohyna/fences.py` | フェンス解読（解析と変換の単一実装） |
| `ohyna/analyze.py` | 静的解析ルール |
| `docs/08` / `docs/09` / `docs/10` | 入力解読・出力・準拠仕様マップの基準文書 |
| `ohyna/server.py` | HTTP・ゲート・docs カタログ |
| `ohyna/frontmatter.py` / `web/src/frontmatter.ts` | 文書設定（両方を揃える） |
| `ohyna/design.py` | フォント・角丸・表紙パターン |
| `ohyna/mermaid_js.py` / `engine.py` | 図描画 |
| `themes/blue-print.css` | 印刷・プレビュー見た目 |
| `styles/*.json` | 色テーマ |
| `web/src/` | GUI |
| `docs/` | 仕様の基準文書（本ファイル群） |

## 3. 仕様と実装の同期

変更したら、影響する `docs/` を同じ作業単位で更新します。外部仕様の版や準拠境界を変える場合は [10-準拠仕様マップ.md](./10-準拠仕様マップ.md) も更新します。

ヘルプに出す文書は `docs/manual/`・`docs/spec/`・`docs/license/` です。章を増減したら `server.py` の `_DOCS_CATALOG` も更新します。構成は **マニュアル／仕様書／ライセンス** の三区分です。

## 4. 変更時チェックリスト

機能や挙動を変えたら、該当するものを確認します。

### 変換・体裁

- [ ] サンプル（`web/src/sample.md`）でプレビューと PDF生成→確認モーダルが通る
- [ ] front matter 必須欠落でプレビュー／PDF が止まる
- [ ] 静的解析 error（壊した Mermaid 等）でプレビュー未更新・PDF 不可・HTTP 422
- [ ] ` ```mermaid ` は図、` ```text ` 内の同内容はコードになる
- [ ] ` ```mermaid code ` は図にならず、Mermaid 色分け付きコードになる
- [ ] ` ```mermaid cdoe `（未知トークン）は `MERMAID_FENCE_MODE` になる
- [ ] 編集画面では `mermaid` と `mermaid code` の両方で Mermaid 構文色分けになる
- [ ] 表紙・余白・見出し帯・表ヘッダが設定どおり
- [ ] KaTeX（インライン／ディスプレイ）がプレビューと PDF で描画される
- [ ] Mermaid 1 図失敗でも（ゲート通過後の）PDF 全体は返る
- [ ] 仕様変更時は [10-準拠仕様マップ.md](./10-準拠仕様マップ.md) の競合規則・基準表も更新する

### GUI

- [ ] `npm run build` 成功
- [ ] 文書設定の適用で YAML が `ohyna:` に書き戻る
- [ ] プレビュー別ウィンドウ（親=エディタのみ、子=プレビュー同期）
- [ ] コンソール垂直 Splitter と別ウィンドウ外だし（履歴同期・行ジャンプ）
- [ ] ヘルプから docs が読める

### セキュリティ

- [ ] bleach 許可を広げた場合は [06-セキュリティ.md](./06-セキュリティ.md) を更新
- [ ] Playwright allowlist 変更時も同左
- [ ] パス拘束（`ensure_under`）を迂回していない

## 5. 確認の目安（手動）

```bash
# PDF
python -m ohyna pdf web/src/sample.md -o out/sample.pdf

# 解析（HTTP）
curl -s -X POST http://127.0.0.1:8787/analyze \
  -H "Content-Type: application/json" \
  -d "{\"markdown\": $(python -c \"import json,pathlib; print(json.dumps(pathlib.Path('web/src/sample.md').read_text(encoding='utf-8')))\")}"
```

入力解読（数式フェンス・Mermaid 形式など）を変えたときは [08-入力解読仕様.md](./08-入力解読仕様.md) とサンプルで目視確認する。
